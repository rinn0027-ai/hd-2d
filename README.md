# hd-2d

Three.js で作った **フル3Dの小惑星アクション** デモ（旧称: HD-2D ジオラマ）。
低ポリの3Dキャラ・地形が球体の上に乗り、ぐるっと一周歩ける「ミニ惑星」を、
ポストプロセスで雰囲気よく見せる実験です。

外部アセットは一切不要 — テクスチャは Canvas、キャラ/物体は **プリミティブ組み立ての3Dモデル**で生成。

## 実装している要素

| 要素 | 内容 |
|------|------|
| 小惑星ワールド | 球体の上を**ぐるっと一周**歩ける（法線=上、重力が球面に沿う）。三人称カメラが惑星を周回 |
| フル3Dモデル | プレイヤー・NPC・敵・木・岩・花・宝箱・ランタンを低ポリ3Dで生成（歩行アニメつき） |
| 歩行アニメ | 手続き生成のスプライトシートを UV オフセットで切替（前/後 + 左右反転 + 2 コマ歩行） |
| Bloom | `UnrealBloomPass`。ランタンの灯り・ホタル・水面のきらめきが発光 |
| 被写界深度 | `BokehPass`（チルトシフト風）。プレイヤーへ自動でピント |
| カラーグレーディング | ビネット / 彩度 / フィルムグレイン + ACES トーンマッピング |
| 揺れる草 | 1400 本の instanced ビルボード草を頂点シェーダーで風に揺らす |
| 水面シェーダー | 波の頂点変位 + ノイズ + 鏡面きらめきのカスタムシェーダー |
| ホタル | additive な GPU パーティクルが明滅しながら漂う（Bloom で発光） |
| 時刻変化 | 夜→夜明け→昼→夕暮れ→夜 で空・太陽・フォグ・ランタンが連動 |
| 影 | PCF ソフトシャドウ |
| ピクセル化 | 低解像度レンダー + 等倍拡大で、よりレトロな質感に切替可能 |
| 空ドーム | グラデーション + 太陽ディスク + 流れる雲（時刻で色が変化） |
| 薄霧 | 地表を漂うボリューム感のあるノイズ霧（ON/OFF） |
| 天候 | 花びら / 雨 を切替（GPUパーティクル、風で舞う） |
| 色収差 + 分離色調 | 周辺の色ズレ、影=寒色・ハイライト=暖色のシネマ調グレード |
| 夜の窓あかり | 時刻が夜になると小屋の窓が emissive で灯る |
| 装飾 | 花畑・岩などの小物を散布、水面に縁の泡 |

右上の **VISUAL FX パネル**で Bloom / 被写界深度 / 時刻 / ピクセル化 / 薄霧 / 色収差 / 天候 を
リアルタイムに切り替えて、画面の作り込みを比較できます。

## ゲーム要素（デモ）

ただの風景デモから一歩進めて、簡単な「遊べる」要素を入れています。

- **NPCとの会話**: 村人・行商人・衛兵・長老に近づいて決定キー。タイプライタ表示の会話ボックス。
- **宝箱**: 調べるとアイテム（やくそう）入手。
- **回合制バトル**: 草むらを歩くと「まもの」とエンカウント → 画面フラッシュ転場 → コマンド戦闘
  （**たたかう / スキル / アイテム / にげる**、ダメージ数字・会心・HP/SPバー・勝敗処理）。
- **マップと当たり判定**: 木・建物・池・NPC を円コリジョンで通り抜け不可。
- **昼夜で変わるBGM**、足音・UI・戦闘の効果音（すべて **Web Audio** で合成、音源ファイル不要）。
- **エリア名トースト**、画面トランジション。

## 操作

即時戦闘（フィールド上で敵とリアルタイムに戦う）。

**PC（キーボード/マウス）**
- 移動: **WASD** / 方向キー &nbsp; 走る: **Shift**
- 攻撃: **J** / マウス左クリック
- ジャンプ: **Space** &nbsp; ダッシュ(回避): **K**
- カメラ回転: **Q** / **E** &nbsp; ズーム: **ホイール**
- 話す / 調べる / 会話送り: **F** / クリック

**スマホ（タッチ）**
- 移動: 画面**左半分**をドラッグ（仮想スティック / 強く倒すと走る）
- カメラ回転: 画面**右半分**を1本指ドラッグ &nbsp; ズーム: **2本指ピンチ**
- 攻撃/話す: 右下の**主ボタン**（近くにNPC/宝箱があれば会話/調べる）
- **JUMP** / **DASH** ボタン

- 右上パネル: Bloom / 被写界深度 / 時刻 / ピクセル化 を調整（スマホはタイトルをタップで開閉）

## 実行方法

ES Modules を使うため、ローカルサーバー経由で開いてください（`file://` 直開きは不可）。

```bash
# どれか一つ
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000`（serve の場合は表示された URL）を開きます。
※ Three.js は CDN(unpkg) から読み込むため、初回はネット接続が必要です。

## 構成

```
index.html        … importmap + UI（パネル/対話/バトル/タッチ）
src/main.js       … シーン構築・ポストプロセス・操作・状態管理・ループ
src/procedural.js … テクスチャ/ドット絵スプライト/敵スプライトの手続き生成
src/battle.js     … 回合制バトル（独自シーン + コマンドUI + 勝敗処理）
src/audio.js      … Web Audio による効果音/BGM合成
assets/           … 任意の外部スプライト素材（player.png を置くと差し替え）
```

## 自前のドット絵に差し替える

`assets/player.png`（透過PNG・ドット絵）を置くと、主役がそのスプライトに置き換わります。
グリッド規格は [`assets/README.md`](assets/README.md) を参照（既定: 横3列の歩行 × 縦2行の前/後）。
列数が違う場合は URL に `?cols=4` のように付けて開きます。
