# hd-2d

Three.js で作った **オクトパストラベラー（HD-2D）風** の 2D-HD ジオラマデモ。
ドット絵スプライト × 3D 空間 × ポストプロセスで、あの「箱庭を覗き込む」質感をどこまで再現できるかを試す実験です。

外部アセットは一切不要 — テクスチャもドット絵キャラも **Canvas でその場生成**しています。

## 実装している HD-2D 要素

| 要素 | 内容 |
|------|------|
| 箱庭パース | 低 FOV(28°) のパースカメラで、ブロックを積んだ立体ジオラマを俯瞰 |
| ビルボード ドット絵 | プレイヤー・木は常にカメラを向く 2D スプライト（最近傍フィルタでドットを保持） |
| 歩行アニメ | 手続き生成のスプライトシートを UV オフセットで切替（前/後 + 左右反転 + 2 コマ歩行） |
| Bloom | `UnrealBloomPass`。ランタンの灯り・ホタル・水面のきらめきが発光 |
| 被写界深度 | `BokehPass`（チルトシフト風）。プレイヤーへ自動でピント |
| カラーグレーディング | ビネット / 彩度 / フィルムグレイン + ACES トーンマッピング |
| 揺れる草 | 1400 本の instanced ビルボード草を頂点シェーダーで風に揺らす |
| 水面シェーダー | 波の頂点変位 + ノイズ + 鏡面きらめきのカスタムシェーダー |
| ホタル | additive な GPU パーティクルが明滅しながら漂う（Bloom で発光） |
| 時刻変化 | 夜→夜明け→昼→夕暮れ→夜 で空・太陽・フォグ・ランタンが連動 |
| 影 | PCF ソフトシャドウ |
| ピクセル化 | 低解像度レンダー + 等倍拡大で、よりレトロな質感に切替可能 |

## ゲーム要素（デモ）

ただの風景デモから一歩進めて、簡単な「遊べる」要素を入れています。

- **NPCとの会話**: 村人・行商人・衛兵・長老に近づいて決定キー。タイプライタ表示の会話ボックス。
- **宝箱**: 調べるとアイテム（やくそう）入手。
- **回合制バトル**: 草むらを歩くと「まもの」とエンカウント → 画面フラッシュ転場 → コマンド戦闘
  （**たたかう / スキル / アイテム / にげる**、ダメージ数字・会心・HP/SPバー・勝敗処理）。
- **マップと当たり判定**: 木・建物・池・NPC を円コリジョンで通り抜け不可。
- **昼夜で変わるBGM**、足音・UI・戦闘の効果音（すべて **Web Audio** で合成、音源ファイル不要）。
- **エリア名トースト**、画面トランジション。

## 操作

**PC（キーボード/マウス）**
- 移動: **WASD** / 方向キー
- ダッシュ: **Shift**
- カメラ回転: **Q** / **E**
- ズーム: **マウスホイール**
- 話す / 調べる / 会話送り: **Space** / **F** / クリック
- バトル: ボタンクリック or **1〜4** キー

**スマホ（タッチ）**
- 移動: 画面**左半分**をドラッグ（フローティング仮想スティック / 強く倒すとダッシュ）
- カメラ回転: 画面**右半分**を1本指でドラッグ
- ズーム: **2本指ピンチ**
- 話す / 調べる / 会話送り: 右下の**○ボタン** or 画面タップ
- バトル: 画面のコマンドボタン

- 右上パネル: Bloom / 被写界深度 / 時刻 / ピクセル化 を調整（スマホはタイトルをタップで開閉）

## 実行方法

ES Modules を使うため、ローカルサーバー経由で開いてください（`file://` 直開きは不可）。

```bash
# どれか一つ
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000`（serve の場合は表示された URL）を開きます。
※ Three.js は CDN(unpkg) から読み込むため、初回はネット接続が必要です。

## 構成

```
index.html        … importmap + UI（パネル/対話/バトル/タッチ）
src/main.js       … シーン構築・ポストプロセス・操作・状態管理・ループ
src/procedural.js … テクスチャ/ドット絵スプライト/敵スプライトの手続き生成
src/battle.js     … 回合制バトル（独自シーン + コマンドUI + 勝敗処理）
src/audio.js      … Web Audio による効果音/BGM合成
```
