# assets — 外部スプライト素材（任意）

ここに **`player.png`** を置くと、プログラム生成のドット絵に代わって
そのスプライトが主役として読み込まれます（無ければ自動生成のまま）。

## player.png の規格

- **形式**: 透過 PNG（ドット絵推奨、にじみ防止のため最近傍で表示されます）
- **グリッド**: 等サイズのコマを格子状に並べる
  - **横 = 歩行コマ**（既定 **3 列**: `静止`, `歩き1`, `歩き2`）
  - **縦 = 向き 2 行**
    - 上段 = **前向き**（カメラ側を向く）
    - 下段 = **後ろ向き**（奥を向く）
- **左右**: 横移動は自動で左右反転するので、左右用のコマは不要
- 1 コマの推奨サイズ: 例 `48×64`px など（比率はキャラの縦長に合わせる）。
  実際のピクセル数は自由 — エンジンが割合でコマを切り出します。

```
            col0(静止)  col1(歩1)  col2(歩2)
row0 前向き [   ●     ][   ●    ][   ●    ]
row1 後向き [   ●     ][   ●    ][   ●    ]
```

## 列数を変えたいとき

歩行コマが 3 列でない場合は、URL に `?cols=` を付けて開く:

```
https://rinn0027-ai.github.io/hd-2d/?cols=4
```

## 反映方法

`player.png` をこのフォルダに置いて push すれば、GitHub Pages 更新後に反映されます。
ローカルなら `assets/player.png` を置いてサーバを再読み込みするだけ。
